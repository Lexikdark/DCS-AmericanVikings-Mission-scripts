SYRIA ISIS Target of Opportunity Script

SYRIA_ISIS_TOO_Script.lua  ·  Dynamic zone discovery, per-zone multi-spawn, water check — ISIS variant of the TOO system for the Syria theatre

How It Works

This script is the Syria-theatre counterpart of the DGSS TOO System v5.9. It discovers TOOZONE_ prefixed trigger zones at runtime (up to 20), spawns 1–3 ISIS target groups per zone, and maintains a minimum active target count on the map. Template sets represent ISIS/Daesh positions including infantry, technicals, AA (ZSU-23-4 Shilka), and mortar emplacements.

Configuration — General

ISIS_TOO_CONFIG.minTargetsOnMap8Minimum active targets maintained on the map at all times.▼ details

Maintenance checks every 60 s. If active count drops below 8, new targets are spawned in available zones. With per-zone multi-spawn, 20 zones can easily hold more than 8 total targets.

ISIS_TOO_CONFIG.maxAttempts12Max spawn retries per target when position fails.▼ details

Applies to each spawnTargetOfOpportunity() call. With the water check enabled, positions landing on water are rejected and a new random point in the zone is tried (up to 5 inner retries per attempt).

ISIS_TOO_CONFIG.maintenanceCheckInterval1800 s (config) / 60 s (actual)Dead-target cleanup and respawn loop interval.▼ details

Same as the TOO System — config declares 1800 s but the actual timer.scheduleFunction runs every 60 s. Ensures fast respawn cycles.

Configuration — Dynamic Zone Discovery

ZONE_SCAN_MAX20Maximum zone index to scan at boot.▼ details

At startup, the script iterates from 1 to 20 and calls trigger.misc.getZone("TOOZONE_" .. i). Found zones are added to ISIS_TOO_ZONES. Gaps are allowed — if TOOZONE_3 is missing but TOOZONE_4 exists, both 1-2 and 4+ are still discovered.

-- Runtime discovery
for i = 1, ZONE_SCAN_MAX do
    local zoneData = trigger.misc.getZone("TOOZONE_" .. i)
    if zoneData then
        ISIS_TOO_ZONES[#ISIS_TOO_ZONES + 1] = {
            name   = "TOOZONE_" .. i,
            point  = zoneData.point,
            radius = zoneData.radius
        }
    end
end
You can add more zones to the ME at any time — just name them TOOZONE_N (up to 20). No script edits needed. To support more than 20, increase ZONE_SCAN_MAX.

Configuration — Per-Zone Spawn Count

MIN_SPAWNS_PER_ZONE1Minimum targets to spawn per zone during initialization.▼ details

Each zone gets at least 1 target group. Tracked in zoneSpawnCount[zoneName].

MAX_SPAWNS_PER_ZONE3Maximum targets per zone during initialization.▼ details

A random count between 1 and 3 is chosen for each zone: math.random(MIN_SPAWNS_PER_ZONE, MAX_SPAWNS_PER_ZONE). This gives density variation — some zones feel empty, others are target-rich. With 20 zones × avg 2 targets = ~40 initial targets.

Water Check

Before spawning at a random position, the script calls:

local surfaceType = land.getSurfaceType({x = pos.x, y = pos.z})
if surfaceType == land.SurfaceType.WATER then
    -- reject position, try another random point
end
This prevents units from spawning on rivers, lakes, or coastal water. The TOO System v5.9 (Afghanistan) lacks this check. On the Syria map with significant coastline, this is essential to avoid lost spawns.

Spawn Flow

  1. Boot: discover all TOOZONE_N zones (N = 1–20).
  2. For each discovered zone, pick math.random(1, 3) spawn count.
  3. For each spawn in a zone:
    1. Pick next template in sequential rotation (cycles 1–30).
    2. Generate random position within zone radius.
    3. Water check — reject if land.SurfaceType.WATER, retry.
    4. Spawn static buildings via mist.dynAddStatic (CJTF_RED).
    5. Spawn unit group via mist.dynAdd (CJTF_RED).
    6. Verify group alive, register in activeTargets, increment zoneSpawnCount.
    7. Place map marker at first unit position.

Maintenance Loop (60 s)

Identical structure to the TOO System v5.9:

  • cleanupDeadTargets() — removes dead groups, decrements zoneSpawnCount, destroys orphaned statics.
  • markerManagerCleanup() — removes markers for dead groups.
  • cleanupPlayerMenus() — clears menu tracking for disconnected players.
  • updateDestroyedBuildings() — counts destroyed statics per group.
  • Re-applies markers to living groups missing one.
  • Spawns new targets until minTargetsOnMap = 8 reached (respects per-zone max of 3).

Map Markers

Each active target gets a map marker prefixed [ISIS_TOO] with the template name and grid reference. Managed by the markerManager — markers are removed automatically when targets die.

Mission Editor Checklist

  1. MIST — MISSION START → DO SCRIPT FILE → mist_4_5_126.lua.
  2. Load script — MISSION START → DO SCRIPT FILE → SYRIA_ISIS_TOO_Script.lua.
  3. Trigger zones — Place circular trigger zones named TOOZONE_1 through TOOZONE_N (up to 20). Gaps are OK. Minimum 1 zone required.
  4. Zone placement (Syria) — The Syria map has significant coastline. Place zones over land. The water check will reject water positions, but zones entirely over water will waste spawn attempts.
  5. Zone radius — 2–10 km recommended. Larger zones spread targets out so multiple groups in one zone don't overlap.
  6. Country — CJTF_RED must be available. Units and statics spawn as this country.
With per-zone multi-spawn (1–3), even 10 zones can produce 10–30 initial targets. You don't need 60 zones like the Afghanistan variant.
