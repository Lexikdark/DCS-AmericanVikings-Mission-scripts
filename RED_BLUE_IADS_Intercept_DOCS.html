RED / BLUE IADS + GCI System

RED_BLUE_IADS_Intercept.lua  ·  Version 1.1  ·  Map: Syria  ·  Requires: MIST 4.5

What This Script Does

A fully scripted, bilateral Integrated Air Defence and Ground Controlled Intercept system for DCS World. Both RED and BLUE coalitions run identical, independent systems simultaneously.

IADS Network

  • EWR nodes share contacts across the SAM network
  • SAMs scored per-engagement; best scorer fires, others go EMCON
  • ARM inbound → suppress radar, optionally relocate
  • SHORAD alerted to incoming AGMs within 15 km

GCI / Intercept

  • Threat detected in a zone → scramble squadron flights
  • DCS radar sensor model used as primary detection
  • AWACS groups extend detection to 420 km
  • AWACS broadcasts picture call every 3 minutes
  • RTB triggered by zone clear or Bingo fuel

Load Order

Create a MISSION START trigger with DO SCRIPT FILE actions in this order:

1.  mist_4_5_126.lua
2.  RED_BLUE_IADS_Intercept.lua
Both files must be in the same folder as your .miz file. The IADS script waits 1 second before initialising, giving MIST time to populate its databases.

Zone Radius Guidance

  • Country-sized sectors: 80–120 km radius
  • Airbase sectors: 60–80 km radius
  • The threat buffer adds an extra 80 km around the zone before scramble — effective trigger distance = zone radius + 80 km.

AWACS Groups

Any group whose name starts with RED_AWACS_ or BLUE_AWACS_ is automatically treated as an AWACS node:

  • Adds a 420 km detection radius to the sphere supplement scan
  • Acts as the GCI reference point for bearing/range in picture calls
  • Triggers coalition-wide picture broadcasts every GCI_PICTURE_INTERVAL seconds, only while alive
No AWACS alive? Picture calls are suppressed. IADS detection still works via DCS radar model + ground EWR sphere fallback.

Intercept Flight Setup in ME

  • Late Activation: ON — required so the script can activate them on demand
  • Uncontrolled: OFF
  • 2 aircraft per group recommended
  • Starting location: parking at the squadron's home airbase
  • No waypoints needed — the script assigns the task after activation

Detection System

Detection runs in two passes every IADS update cycle. Both passes contribute to the final contact list, deduplicated by unit name.

Pass 1 — DCS Radar Sensor Model PRIMARY

Calls coalition.getDetectedTargets(coalID, Unit.SensorType.RADAR). Uses DCS built-in radar simulation:

  • Beam shape, pulse repetition, radar cross-section of target
  • Line-of-sight terrain masking
  • ECM / jamming effects
  • Target aspect and doppler

Any radar-equipped SAM or EWR in the coalition contributes, regardless of whether it's named in the script. Disable with USE_DCS_DETECTION = false.

Pass 2 — Range Sphere Supplement SECONDARY

Always runs. Iterates named EWR nodes (250 km), SAM nodes (150 km) and AWACS groups (420 km). Captures aircraft the physics model may miss (e.g. SAM radar was off for EMCON, or target is within AWACS range but outside ground coverage).

IADS Network

The shared air picture is the same for all SAM nodes in a coalition. Any EWR or SAM that detects a contact adds it to the coalition picture — all SAMs can be tasked against it without needing their own sensor lock.

SAM Behaviour

  • SAMs with an assigned engagement target: radar ON, EngageUnit task pushed
  • SAMs with no target: radar OFF (EMCON / standby) — reduces SEAD exposure
  • Fire delay randomised between SAM_FIRE_DELAY_MIN and SAM_FIRE_DELAY_MAX to stagger launches

SAM Engagement Scoring

When multiple SAMs can engage a contact, the highest scorer fires; others remain on standby.

Score = PKill_BASE x rangeFactor x altFactor x healthFactor
FactorFormulaNotes
rangeFactor1 - |d/maxRange - 0.4|Peaks at 40% of max range; near-zero at extremes
altFactorLinear ramp below 500 m and above 12 000 mPrefers targets 500–12 000 m AGL
healthFactoralive_units / total_unitsDegraded sites score lower
PKill_BASEConfig value (default 0.75)Global tuning multiplier

Suppressed SAMs (ARM evasion window active) are skipped — score forced to 0.

ARM & AGM Defence

Monitored on every S_EVENT_SHOT. Weapons are classified by checking getTypeName() against ARM_TYPES and AGM_TYPES using string.find() (partial match; both hyphen and underscore forms listed).

ARM Response

ARM detected
→
Extrapolate trajectory 60 s forward
→
Find nearest SAM to projected impact
→
Suppress radar for ARM_SHUTDOWN_TIME (45 s)
→
Mobile SAM relocates up to ARM_MOVE_RADIUS (800 m)
→
Radar back online after window

AGM Response

Tracked in the weapon loop (every 1 second). Any SHORAD node within 15 km of the weapon's current position is alerted and set Weapons Free.

GCI & Scramble System

Runs for both coalitions every AIR_INTERCEPT_INTERVAL seconds (default 10 s).

Scramble Flow

Enemy contacts in coalition picture
→
Filter contacts within 80 km of squadron zone
→
threats > 0 → check airborne vs maxFlights
→
Get available late-activate groups (MIST DB)
→
Activate + assign EngageUnit or Orbit task
→
GCI scramble message to coalition

Scramble Message Format

[GCI MOSCOW]  FOXBAT, SCRAMBLE. Vector 287 / 62 nm, 2 high, 1 medium. 3 hostile(s). Cleared to engage.

Task Assignment (4 s after activation)

  • Lead threat unit still alive: EngageUnit task assigned
  • Threat gone: Orbit task over zone centre at INTERCEPT_ALTITUDE
  • ROE set to Weapons Free, threat reaction set to aggressive

AWACS Picture Call

Broadcasts to the coalition every GCI_PICTURE_INTERVAL seconds (default 3 min), only while at least one AWACS group is alive.

Message Format

[MAGIC]  PICTURE: 4 contact(s), 287 / 62 nm, 2 high, 2 medium.
[OVERLORD]  PICTURE CLEAR. No enemy contacts.

Bearing is from the AWACS aircraft's current position (or first EWR node if no AWACS is alive). Range in nautical miles.

BandAGL
lowBelow 3 000 m
medium3 000 – 7 500 m
highAbove 7 500 m

RTB Logic

TriggerConditionGCI Message
Zone clear No threats within 80 km for RTB_LOITER_TIME seconds (default 120 s) [GCI MOSCOW] FOXBAT, RTB. Zone clear.
Bingo fuel Any unit drops below GCI_FUEL_RTB_THRESHOLD (default 20%) [GCI MOSCOW] FOXBAT, RTB. Bingo fuel (18%).

RTB Sequence

  1. ROE set to Return Fire Only
  2. Task assigned: waypoint to homeBase → Land action
  3. 600 seconds later: group destroyed, status set to "standby"
  4. Group is now eligible for re-dispatch if threats return
Groups are destroyed after landing — not deactivated. They cannot be re-activated after destruction. Plan your late-activate pool accordingly (3 groups per sector is a good baseline for a 4-hour mission).

Node Refresh Loop

Runs every NODE_REFRESH_INTERVAL seconds (default 900 s / 15 min). Calls buildNodeList() for both coalitions — scans all groups by prefix and keeps only those with at least one alive unit.

  • Dead SAM / EWR groups silently removed
  • No respawn — SAM sites are one-and-done
  • log output: [NodeRefresh] Done. RED nodes: 12 BLUE nodes: 4

Troubleshooting

SymptomLikely Cause & Fix
No intercept flights launch 1. Check groups have Late Activate = ON.
2. groupPrefix in SQUADRONS must exactly match the start of the ME group name.
3. Verify MIST is loaded first.
4. Zone name in SQUADRONS must match ME trigger zone exactly (case-sensitive).
No AWACS picture calls Verify at least one RED_AWACS_ / BLUE_AWACS_ group is alive. Check prefix matches AWACS_PREFIX_RED / AWACS_PREFIX_BLUE.
SAMs not engaging Check SAM groups start with RED_SAM_ / BLUE_SAM_. Verify at least one EWR is alive within 250 km, or USE_DCS_DETECTION = true and coalition radar is active.
ARM not detected Confirm weapon's getTypeName() appears in ARM_TYPES. Use env.info(tostring(weapon:getTypeName())) in a test script to print the exact string.
Zones not discovered MIST version may not expose mist.DBs.zonesByName. Manually register via registerRedZone() / registerBlueZone() in a DO Script at T+2 s.
Flights RTB immediately Check GCI_FUEL_RTB_THRESHOLD. If set too high and aircraft spawn with partial fuel, they Bingo at start. Default 0.20 is safe for most aircraft.
All script errors Search dcs.log for [IADS] — all script output is prefixed with this tag. Most common issue: loading IADS script before MIST (check trigger order).
