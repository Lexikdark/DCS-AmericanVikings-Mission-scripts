Overview

RaceScript V4.0 is a Lua timing script for DCS World multiplayer servers. It tracks each player independently through a series of trigger zones (gates) placed in the Mission Editor, times them from start to finish with hundredths-of-a-second accuracy, and logs completed runs to a text file.

[StartingLine] → Gate 1 → Gate 2 → Gate 3 → ... → Gate 20 → [FinishLine]

Requirements

  • REQUIRED MIST (Mission Scripting Tools) — must be loaded before this script. MIST provides mist.DBs.humansByName, mist.scheduleFunction, and other utilities the script depends on.
  • REQUIRED DCS desanitized io and lfs — the script writes the log file using io.open and reads the Saved Games path using lfs.writedir(). These must be un-commented in MissionScripting.lua.
  • OPTIONAL DCS version 2.7+ recommended (older versions untested).

Desanitizing MissionScripting.lua

Open DCS World\Scripts\MissionScripting.lua and comment out (add --) the lines that sanitize io and lfs:

-- sanitizeModule('io')
-- sanitizeModule('lfs')
⚠ This allows any mission script to read/write files on the server. Only do this on servers you control.

Mission Editor Setup

All the script needs from the Mission Editor are trigger zones. No units, no triggers panel logic — just zones and a "DO SCRIPT FILE" action to load the scripts.

Step 1 — Place Trigger Zones

In the Mission Editor, open the trigger zones panel and create circular zones with exactly these names:

Zone NamePurposeNotes
StartingLineStarts the timer when a player flies throughPlace at the beginning of the course
Gate 1 through Gate 20Checkpoints along the race courseMust be flown through in order
FinishLineStops the timer and logs the resultPlace at the end of the course
✔ Zone names are case-sensitive and must match exactly — Gate 1 (capital G, space, number). The script validates all zones at startup and will tell you which ones are missing.

Step 2 — Size Your Zones

Zone radius matters! A too-small zone is easy to miss at high speed. Recommendations:

  • Mountain pass / canyon gates: 150–300 m radius
  • Open-area checkpoints: 300–600 m radius
  • Start & Finish lines: 400–800 m radius (be generous so players don't accidentally miss them)

Step 3 — Load the Scripts

In the Triggers panel, create a trigger that fires ONCE at MISSION START:

  1. Action: DO SCRIPT FILE → select MIST.lua (or however your MIST file is named)
  2. Action: DO SCRIPT FILE → select RaceScript_V4.0.lua
⚠ MIST must load first. If RaceScript loads before MIST, it will crash immediately because mist.DBs won't exist.

Configuration

All configurable values are near the top of the script (around lines 83–101). Here's what each one does:

VariableDefaultWhat It Does
startZoneName "StartingLine" Name of the trigger zone that starts the timer. Change this if you want a different zone name in the editor.
endZoneName "FinishLine" Name of the trigger zone that stops the timer and logs the run.
zonesToTime {"Gate 1", ..., "Gate 20"} The ordered list of checkpoint gates. See Adding / Removing Gates below.
altitudeLimit 250 Maximum altitude AGL (Above Ground Level) in meters. A zone only registers if the player is below this. Prevents high-altitude flyovers from triggering gates.
penaltyTime 5 Seconds added to the final time for each missed gate.
logFileName lfs.writedir() .. "PlayerTimesLog.txt" Full path to the log file. By default this writes to your Saved Games\DCS\ folder.

Adding / Removing Gates

The gate list lives in the zonesToTime table. To change the number of gates, you only need to edit this one table — the rest of the script adapts automatically.

Adding Gates

Say you want to add 5 more gates (21–25):

1. In the Mission Editor, create five new trigger zones named exactly Gate 21, Gate 22, Gate 23, Gate 24, Gate 25.

2. In the script, add them to the end of the table: 
local zonesToTime = {
    "Gate 1",
    "Gate 2",
    "Gate 3",
    -- ... gates 4-20 ...
    "Gate 20",
    "Gate 21",   -- NEW
    "Gate 22",   -- NEW
    "Gate 23",   -- NEW
    "Gate 24",   -- NEW
    "Gate 25"    -- NEW  (no trailing comma on the last one)
}

Removing Gates

To go from 20 gates down to 10, simply delete lines from the table and remove the matching trigger zones from the mission (or leave them — unused zones are harmless, but the script will warn about them at startup since it tries to validate everything in the list).

local zonesToTime = {
    "Gate 1",
    "Gate 2",
    "Gate 3",
    "Gate 4",
    "Gate 5",
    "Gate 6",
    "Gate 7",
    "Gate 8",
    "Gate 9",
    "Gate 10"
}

Custom Gate Names

Gates don't have to be called "Gate N". You can use any name as long as it matches the trigger zone name exactly:

local zonesToTime = {
    "Canyon Entry",
    "Bridge Underpass",
    "Ridge Climb",
    "Valley Floor",
    "Tunnel Exit"
}
✔ The order in the table is the order the player must fly them. Gate sequence is determined by position in this list, not by the zone name.

Renaming Start / Finish Zones

If you prefer different names, change these two lines:

local startZoneName = "RaceStart"    -- was "StartingLine"
local endZoneName   = "RaceFinish"   -- was "FinishLine"

Then rename the trigger zones in the Mission Editor to match.

How It Works

Timing

Each player gets their own Stopwatch object. The stopwatch uses timer.getTime() (DCS simulation clock) and records elapsed time to hundredths of a second. Three functions run every 0.1 seconds:

  1. checkStartZone — Scans all human players. If a player is inside the StartingLine zone and doesn't already have a timer running, it creates a new Stopwatch and starts it.
  2. checkTimedZones — For each player with an active timer, checks if they're inside the next expected gate. If they hit a gate further ahead, the skipped gates are counted as missed.
  3. checkEndZone — When a player with an active timer enters the FinishLine zone, the stopwatch stops, penalties are calculated, and the result is logged.

Gate Sequence Detection

The script tracks which gate each player should hit next. When a player enters a gate zone:

  • Correct gate → Time is reported, gate is marked as passed, sequence advances.
  • Skipped ahead (e.g. hit Gate 8 when Gate 6 was expected) → Gates 6 and 7 are marked as missed. The player sees exactly which gates they missed and their time penalty. Gate 8 is recorded as passed normally.

What Counts as "Inside a Zone"

A player registers as being inside a zone when both conditions are true:

  1. Their horizontal distance from the zone center is less than the zone's radius.
  2. Their altitude AGL (Above Ground Level) is below altitudeLimit (default: 250 m).

This means you can't cheat by flying over a zone at 10,000 feet.

Race Reset

Each player's group gets a "Reset My Race" radio menu command (F10 menu) the first time anyone in that group crosses the starting line. This resets only pilots in the same group — it won't affect other players on the server.

Crash / Death Handling

If a player crashes, is killed, or ejects during an active race, the run is immediately nullified. No time is logged. The player sees a message telling them to cross the Starting Line to begin again.

Disconnect Detection

If a player disconnects mid-race (or their aircraft despawns), the script detects this within 30 seconds and cleans up their race data automatically.

Corpse Cleanup

Every 45 minutes, the script scans all coalitions for destroyed aircraft/helicopter wrecks and removes them so they don't clutter the race course.

Race Rules

RuleWhat Happens
Miss 1 gate +5 seconds penalty (configurable). Time is still logged. Player is told which gate was missed.
Miss 2+ gates Race is NULLIFIED. No time is logged. Player must cross the Starting Line to try again.
Crash / die mid-race Race is NULLIFIED. No time is logged.
Fly above altitude limit Gate doesn't register — treated as if you missed it.
Fly gates out of order Any gates between your last valid gate and the one you hit are marked as missed.

Example Scenario

A pilot flies through Gates 1–15 perfectly. In a tight mountain pass with Gates 15, 16, and 17 close together, they miss Gate 16 but hit Gate 17.

  • Immediately sees: "⚠ MISSED: Gate 16! +5s penalty"
  • Gate 17 is recorded normally.
  • They continue through Gates 18, 19, 20 and cross the Finish Line.
  • Final time = raw time + 5 seconds, with "(+5s penalty: missed Gate 16)" in the result.

Now imagine they also missed Gate 20:

  • At the moment Gate 20 is detected as missed (when they pass it or hit the Finish Line), the race is nullified.
  • They see: "✗ Race NULLIFIED — missed 2 gates (Gate 16, Gate 20). Cross the Starting Line to begin again."
  • No time is logged. Must start over.

Log File

Completed runs are appended to:

C:\Users\YourName\Saved Games\DCS\PlayerTimesLog.txt

Each line looks like:

Nickname: Viper11 | Aircraft: F-16C_50 | Time: 142.37s | Missed Gates: None
Nickname: Hornet23 | Aircraft: FA-18C_hornet | Time: 158.84s | Missed Gates: Gate 12
✔ Nullified runs (2+ missed gates or crash) are never written to the log. Only complete, valid runs appear.

Troubleshooting

"RACE SETUP ERROR: Missing X zones!"

The script validates all zones at startup. If any are missing, it lists them and refuses to start. Fix: open the Mission Editor and make sure every zone name in zonesToTime (plus StartingLine and FinishLine) exists as a trigger zone with the exact same name.

"Cannot open log file"

The io and/or lfs libraries are still sanitized. Open DCS World\Scripts\MissionScripting.lua and comment out the sanitize lines. See Requirements.

Timer never starts

  • Make sure MIST is loaded before the race script.
  • Make sure you're flying below the altitude limit (default 250 m AGL) when crossing the Starting Line.
  • Check that the StartingLine zone radius is large enough for your approach speed.

Gates not registering

  • You might be above the altitude limit. The zone only triggers below altitudeLimit meters AGL.
  • Zone radius might be too small for the aircraft's speed. At 500 knots, you cover ~260 m every 0.1 seconds (the polling interval). A zone with a 100 m radius could be missed entirely. Use at least 200–300 m radius for high-speed sections.
  • Gates must be flown in order. If you skipped one, the next one won't register until you either hit it or fly through a later gate (which marks the skipped one as missed).

"Reset My Race" not appearing in F10 menu

The reset command only appears after a pilot in your group crosses the Starting Line for the first time. It won't be there before you've started at least one race.

Server Operators: If you change the gate list, remember to update both the script AND the mission file. The script will tell you at startup if they're out of sync.
